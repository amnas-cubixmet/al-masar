# AL MASAR YELLOW Company Website

Component-based Next.js public website starter for AL MASAR YELLOW Company.

## Features
- Dark industrial brand UI
- Responsive from 320px
- 2 product cards per row on small mobile screens
- Product category filtering
- Global product search
- Individual product detail routes
- Branch selector with dynamic phone, WhatsApp, address and map
- English / Arabic selector with RTL handling
- Client, About, Branches and Contact pages
- Next/Image optimization and lazy loading

## Start
```bash
npm install
npm run dev
```
Open http://localhost:3000
